## 📌 About

**Flask Docker App** is a simple Python web application developed using **Flask** and containerized using **Docker**.

The project demonstrates the basic Docker workflow:

```text
🐍 Flask Application
        ↓
🐳 Dockerfile
        ↓
📦 Docker Image
        ↓
🚢 Docker Container
        ↓
🌐 Web Application
```

This project was created to gain practical hands-on experience with **Python, Flask, Docker, Linux, containers, images, and port mapping**.
